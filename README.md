# 🚀 Digitools Platform

A modern, responsive web platform built with React and Tailwind CSS to showcase digital tools, services, and products with a clean UI and dynamic features.

---

## 📌 Features

* ⚡ Fast and responsive design
* 🎨 Built with Tailwind CSS & DaisyUI
* 🛒 Dynamic cart system
* 📦 Product listing with tags (Popular, New, Best Seller)
* 🔍 Clean and reusable components
* 📱 Mobile-friendly layout

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Styling:** Tailwind CSS, DaisyUI
* **State Management:** useState (React Hooks)
* **Icons:** React Icons / Lucide

## ⚙️ Installation

Follow these steps to run the project locally:

```bash
# Clone the repository
git clone https://github.com/your-username/digitools-platform.git

# Go to project folder
cd digitools-platform

# Install dependencies
npm install

# Run the project
npm run dev

#Install daisyui 
npm i -D daisyui@latest

#Install tailwind css
npm install tailwindcss @tailwindcss/vite

#Build the project 
npm run build

```
